# Surya Sri Venkat - Portfolio

Personal portfolio of Surya Sri Venkat Annabathuni, an MSc Computer Vision,
Robotics and Machine Learning student at the University of Surrey.

The site brings together my work across machine learning, data science,
bioinformatics, full-stack development and automation. It also includes a more
personal hobbies section for cinema, music, Letterboxd and a future photography
album.

## Highlights

- Responsive Midnight Nocturne visual design
- Project archive with live demos and source links
- Experience, education and technical skills
- Interactive portrait and fan-art flip card
- Random-track Night Radio using official YouTube embeds
- Letterboxd profile and future photography space
- Reduced-motion and keyboard-accessibility support

## Technology

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- CSS animations and responsive layouts

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production build

```bash
npm run build
npm start
```
